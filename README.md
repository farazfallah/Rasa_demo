# نسخه نمایشی و سایت معرفی سامانه رسا

این مخزن کاملا جدا از خود اپ است و هیچ کدی در اپ اضافه نمی‌کند. نسخه نمایشی همان ایمیج‌های رسمی اپ (`madreseh-api` و `madreseh-web`) را اجرا می‌کند.

| پوشه | کار |
|---|---|
| `site/` | سایت معرفی ایستا با فرم «درخواست دمو» |
| `kit/` | سرویس کوچک دمو: ساخت مدرسه نمونه، بازسازی شبانه، پنل درخواست‌ها و ساخت حساب متقاضیان |
| `deploy/` | docker-compose و Caddy برای اجرای همه‌چیز روی یک سرور (با HTTPS خودکار) |

## روند دسترسی متقاضی

۱. متقاضی فرم سایت را پر می‌کند (نام، مدرسه، سمت، موبایل، شهر، تعداد دانش‌آموز، توضیحات).

۲. درخواست در پنل `https://SITE_DOMAIN/panel` نمایش داده می‌شود (ورود با `PANEL_USER` / `PANEL_PASSWORD`).

۳. با «تأیید و ساخت دسترسی»، کیت در چند ثانیه این‌ها را از طریق API رسمی اپ می‌سازد:
   - یک کلاس اختصاصی پایه هشتم با ۱۲ دانش‌آموز، پرونده کامل و والدین
   - سابقه کلاس: حضور و غیاب، نمره، انضباط، دفتر کلاسی، تکالیف و پاسخ‌ها، شهریه، آزمون آنلاین و فرم رضایت‌نامه
   - چهار حساب با یک رمز مشترک:

| حساب | نام کاربری (کد ۱۰۱) | نقش |
|---|---|---|
| مدیر | `m101` | «مدیر (نسخه نمایشی)»: همه امکانات به جز مدیریت کاربران، نقش‌ها و تنظیمات |
| معلم | `t101` | معلم همه درس‌های کلاس اختصاصی |
| ولی | `p101` | ولی دانش‌آموز آن کلاس |
| دانش‌آموز | `s101` | دانش‌آموز همان کلاس (آزمون آنلاین باز را خودش امتحان می‌کند) |

۴. دکمه «کپی متن دسترسی» متن آماده نشانی، نام‌های کاربری، رمز و تاریخ اعتبار را کپی می‌کند تا هر طور خواستید (تلفن، پیام‌رسان) بفرستید. پیامکی ارسال نمی‌شود.

۵. مدت پیش‌فرض ۷ روز است (`LEAD_DAYS`). در پنل قابل تمدید، قطع یا فعال‌سازی دوباره است. پس از پایان مهلت، حساب‌ها خودکار غیرفعال می‌شوند.

## مدرسه نمونه و بازسازی شبانه

- «دبیرستان نمونه رسا»: پایه‌های هفتم تا نهم، ۹ کلاس، ۲۷۰ دانش‌آموز با والدین، ۱۶ معلم، معاون، حسابدار و کتابدار
- سال تحصیلی جاری از ۱ مهر تا دیروز، و سال قبل به‌طور کامل با کارنامه منتشرشده
- برنامه هفتگی با زمان‌بند خود اپ، تعطیلات رسمی، کتابخانه، اطلاعیه‌ها، تکالیف، آزمون آنلاین و فرم اردو
- همه نام‌ها و کدهای ملی ساختگی‌اند (کد ملی با رقم کنترل معتبر). داده با seed ثابت ساخته می‌شود و هر شب همان مدرسه با تاریخ‌های به‌روز ساخته می‌شود.

هر شب ساعت `RESET_AT` (پیش‌فرض ۳:۳۰ به وقت تهران):

۱. صفحه «در حال به‌روزرسانی» روی دامنه دمو نمایش داده می‌شود.

۲. همه جدول‌ها خالی می‌شوند (ساختار و migrationها دست نمی‌خورند)، کش Redis و فایل‌های بارگذاری‌شده پاک می‌شوند و seed پایه خود اپ اجرا می‌شود.

۳. مدرسه نمونه از طریق API ساخته می‌شود (حدود ۲ دقیقه).

۴. حساب متقاضیان فعال با همان نام کاربری و رمز دوباره ساخته می‌شود (هر نفر چند ثانیه).

اگر ساخت به هر دلیلی ناموفق باشد، هر ۱۰ دقیقه دوباره تلاش می‌شود. از پنل هم می‌شود «بازسازی کامل الان» را زد.

## نصب روی سرور

پیش‌نیاز: سرور لینوکس با Docker، دو دامنه (مثلا `rasa.example.com` و `demo.rasa.example.com`) که به IP سرور اشاره کنند، و پورت‌های ۸۰ و ۴۴۳ باز.

```bash
git clone <این مخزن> rasa-demo && cd rasa-demo/deploy

# ایمیج‌های اپ از بسته انتشار (school-app-X.Y.Z.tar.gz)
tar -xzf school-app-1.4.0.tar.gz && docker load -i school-app-1.4.0/images.tar

cp .env.example .env    # دامنه‌ها، نسخه اپ و رمزها را تنظیم کنید
docker compose up -d --build
```

ساخت اولیه مدرسه نمونه چند دقیقه طول می‌کشد؛ وضعیت در پنل دیده می‌شود.

### به‌روزرسانی اپ دمو

```bash
cd rasa-demo/deploy
./update-demo.sh            # آخرین نسخه منتشرشده رسا در GitHub (اگر جدیدتر باشد)
./update-demo.sh 1.5.0      # نسخه مشخص
./update-demo.sh --file school-app-1.5.0.tar.gz   # از فایل بسته انتشار، بدون اینترنت
```

اسکریپت بسته انتشار را دریافت و sha256 را بررسی می‌کند، ایمیج‌ها را بارگذاری می‌کند، `APP_VERSION` را در `.env` تنظیم و سرویس‌ها را دوباره راه‌اندازی می‌کند. کیت دمو با دیدن نسخه جدید، مدرسه نمونه و حساب متقاضیان فعال را خودکار روی نسخه جدید از نو می‌سازد (چند دقیقه؛ صفحه «در حال به‌روزرسانی» نمایش داده می‌شود).

برای به‌روزرسانی خودکار، هر شب قبل از بازسازی ۳:۳۰ (با `crontab -e`):

```
0 3 * * * /path/to/rasa-demo/deploy/update-demo.sh >> /var/log/rasa-demo-update.log 2>&1
```

### ایمنی

- رمز حساب `admin` اپ دمو (`DEMO_ROOT_PASSWORD`) فقط برای شماست و به متقاضیان داده نمی‌شود.
- متقاضیان نقش مدیر کامل ندارند: کاربر نمی‌سازند، رمز دیگران را عوض نمی‌کنند و به تنظیمات، نقش‌ها، پیامک و دستگاه‌ها دسترسی ندارند.
- تغییر رمز و مشخصات حساب روی دامنه دمو در Caddy بسته است.
- پیامک‌های اپ دمو فقط در لاگ نوشته می‌شوند (سرویس پیامک تنظیم نشده است).
- درگاه آزمایشی خود اپ در نسخه production غیرفعال است؛ برای نمایش پرداخت آنلاین، شناسه sandbox زرین‌پال را در `ZARINPAL_SANDBOX_MERCHANT` بگذارید.
- فرم درخواست: فیلد پنهان ضدربات، حداکثر ۵ درخواست در ساعت برای هر IP و ثبت نکردن درخواست تکراری از یک موبایل.
- درخواست‌ها و وضعیت کیت در volume `kitdata` (فایل `/data/kit.json`) نگه داشته می‌شوند.

## اجرای محلی کیت (توسعه)

API اپ را روی یک پایگاه داده جدا اجرا کنید (migrationها اجرا شده باشند)، سپس:

```bash
cd kit && npm install
export API_URL=http://localhost:3001/api
export DATABASE_URL=postgres://madreseh:madreseh@localhost:5432/madreseh_demo
export REDIS_URL=redis://localhost:6379/2
export SEED_COMMAND="node ../school_app/apps/api/dist/db/seed.js"
export DEMO_ROOT_PASSWORD=... PANEL_PASSWORD=... DATA_DIR=./data
node src/cli.js rebuild     # ساخت کامل
node src/server.js          # پنل روی http://localhost:8090/panel
npm test
```

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `STUDENTS_PER_CLASS` | ۳۰ | دانش‌آموز هر کلاس مدرسه نمونه |
| `LEAD_STUDENTS` | ۱۲ | دانش‌آموز کلاس اختصاصی هر متقاضی |
| `PREVIOUS_YEAR` | ۱ | ساخت سال تحصیلی قبل (۰ = خاموش) |
| `KIT_WORKERS` | ۳ | حساب‌های کمکی برای پخش درخواست‌ها (سقف درخواست هر حساب در دقیقه) |
| `BUILD_ON_START` | ۱ | ساخت خودکار در اولین اجرا |
